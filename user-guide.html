1. Pengenalan Aplikasi

E-Mading (Electronic Magazine Dinding) adalah aplikasi web yang memungkinkan siswa dan guru berkolaborasi dalam membuat dan mengelola konten artikel sekolah secara digital.

Tujuan Aplikasi

  • Digitalisasi mading sekolah tradisional
  • Meningkatkan partisipasi siswa dalam menulis
  • Memudahkan pengelolaan konten oleh guru
  • Menyediakan platform berbagi informasi sekolah
Teknologi yang Digunakan:
Framework: Laravel 11 | Database: SQLite/MySQL | Frontend: Blade + Tailwind CSS

2. Instalasi dan Setup

Langkah Instalasi:

  1. Clone repository dari Git
  2. Jalankan composer install untuk menginstall dependencies
  3. Copy file .env.example menjadi .env
  4. Generate application key dengan php artisan key:generate
  5. Jalankan migration dan seeder: php artisan migrate --seed
  6. Buat storage link: php artisan storage:link
  7. Jalankan server: php artisan serve
Catatan Penting: Pastikan PHP versi 8.1+ dan Composer sudah terinstall di sistem Anda.

3. Akun Default

Setelah menjalankan seeder, tersedia akun default berikut:

Role Username Password Keterangan
Admin admin admin123 Akses penuh ke semua fitur
Guru guru guru123 Dapat mengelola artikel dan menyetujui publikasi
Siswa ramdhani siswa123 Dapat menulis artikel dan berkomentar

4. Cara Login

Langkah Login:

  1. Buka aplikasi di browser (biasanya http://localhost:8000)
  2. Klik tombol "Login" di halaman utama
  3. Masukkan username dan password sesuai role Anda
  4. Klik tombol "Masuk"
  5. Anda akan diarahkan ke dashboard sesuai role

5. Panduan untuk Siswa

🎓 Fitur untuk Siswa

  • Membuat artikel baru
  • Mengedit artikel milik sendiri
  • Membaca dan berkomentar pada artikel
  • Memberikan like pada artikel

5.1 Membuat Artikel Baru

  1. Login dengan akun siswa
  2. Klik menu "Artikel Saya" di dashboard
  3. Klik tombol "Buat Artikel Baru"
  4. Isi form artikel:
    • Judul: Masukkan judul artikel yang menarik
    • Kategori: Pilih kategori yang sesuai
    • Isi Artikel: Tulis konten artikel
    • Foto: Upload gambar pendukung (opsional)
  5. Klik "Simpan" untuk menyimpan sebagai draft
Catatan: Artikel yang dibuat siswa akan tersimpan sebagai draft dan perlu persetujuan guru untuk dipublikasikan.

5.2 Mengedit Artikel

  1. Buka halaman "Artikel Saya"
  2. Cari artikel yang ingin diedit
  3. Klik tombol "Edit" pada artikel tersebut
  4. Lakukan perubahan yang diperlukan
  5. Klik "Update" untuk menyimpan perubahan

5.3 Berkomentar dan Like

  1. Buka artikel yang ingin dikomentari
  2. Scroll ke bagian bawah artikel
  3. Tulis komentar di kolom yang tersedia
  4. Klik "Kirim Komentar"
  5. Untuk like, klik ikon ❤️ di artikel

6. Panduan untuk Guru/Admin

👨‍🏫 Fitur untuk Guru/Admin

  • Menulis artikel sendiri
  • Mengedit semua artikel
  • Menyetujui artikel siswa
  • Mengelola komentar
  • Generate laporan
  • Melihat dashboard statistik

6.1 Menyetujui Artikel Siswa

  1. Login dengan akun guru/admin
  2. Buka menu "Kelola Artikel"
  3. Lihat daftar artikel dengan status "Draft"
  4. Klik "Lihat" untuk membaca artikel
  5. Jika artikel layak, klik "Setujui untuk Publikasi"
  6. Artikel akan muncul di halaman utama

6.2 Mengelola Artikel

  1. Buka menu "Kelola Artikel"
  2. Lihat semua artikel (draft dan published)
  3. Gunakan tombol aksi:
    • Edit: Mengubah konten artikel
    • Hapus: Menghapus artikel
    • Publish/Unpublish: Mengatur status publikasi

6.3 Generate Laporan

  1. Buka menu "Laporan"
  2. Lihat statistik artikel yang dipublikasikan
  3. Klik "Cetak Laporan" untuk mencetak
  4. Laporan menampilkan:
    • Total artikel published
    • Detail setiap artikel
    • Jumlah likes dan komentar
    • Tanggal publikasi

6.4 Dashboard Statistik

Dashboard admin menampilkan:

  • Total artikel published
  • Total artikel draft
  • Total pengguna
  • Artikel terpopuler
  • Aktivitas terbaru

7. Panduan untuk Pengunjung

👥 Fitur untuk Pengunjung

  • Membaca artikel yang dipublikasikan
  • Melihat artikel tanpa login
  • Browse berdasarkan kategori

7.1 Membaca Artikel

  1. Buka halaman utama aplikasi
  2. Lihat daftar artikel yang dipublikasikan
  3. Klik judul artikel untuk membaca selengkapnya
  4. Gunakan filter kategori untuk mencari artikel spesifik
Batasan Pengunjung: Pengunjung tidak dapat menulis artikel, berkomentar, atau memberikan like tanpa login.

8. Fitur Keamanan

Sistem Keamanan yang Diterapkan:

  • Role-based Access Control: Setiap user memiliki role dengan hak akses berbeda
  • Artikel Ownership: Siswa hanya dapat mengedit artikel milik sendiri
  • Approval System: Artikel siswa harus disetujui sebelum dipublikasikan
  • Input Validation: Semua input divalidasi untuk mencegah serangan
  • File Upload Security: Validasi tipe dan ukuran file
  • CSRF Protection: Perlindungan terhadap serangan CSRF

9. Troubleshooting

9.1 Masalah Umum dan Solusi

❌ Tidak Bisa Login

Solusi:

  • Pastikan username dan password benar
  • Cek apakah database sudah di-seed
  • Periksa koneksi database di file .env

❌ Gambar Tidak Muncul

Solusi:

  • Jalankan php artisan storage:link
  • Periksa permission folder storage
  • Pastikan file gambar ter-upload dengan benar

❌ Error 500 Internal Server

Solusi:

  • Periksa log error di storage/logs/laravel.log
  • Pastikan semua dependencies ter-install
  • Cek konfigurasi database
  • Jalankan php artisan config:clear

❌ Artikel Tidak Muncul di Halaman Utama

Solusi:

  • Pastikan artikel sudah di-approve oleh guru
  • Cek status artikel (harus "published")
  • Refresh halaman atau clear cache browser
